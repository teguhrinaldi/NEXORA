# Changelog

## 1.0.0

Initial release.

- Public marketing site: homepage with product, AI Studio, automation, prompt library, document workspace, and analytics previews, testimonials, pricing preview, FAQ, and final CTA; a dedicated pricing page with a monthly/yearly toggle.
- Authentication screens: login, registration, and a forgot/reset password flow, all with validation, loading, error, and success states.
- A six-step onboarding flow: welcome, goal selection, workspace type, tool preferences, optional team invites, and completion.
- Application shell: collapsible sidebar, mobile drawer, topbar with search, credits indicator, notifications, and account menu, and a keyboard-accessible command palette (`Ctrl/⌘ K`).
- Five dashboard variants — Overview, Creator, Team, Automation, and Analytics — sharing one design system and switchable from a single view.
- AI Studio with eight capability modes, model/tone/length/language controls, attachments, and a response panel with copy, regenerate, export, save-to-document, and save-as-prompt actions.
- A chat workspace with conversation management (create, rename, archive, delete) and simulated streaming-style responses, including a realistic failure/retry state.
- A prompt library with categories, favorites, recently used, variable substitution, and a direct hand-off into AI Studio.
- A document workspace with folders, an AI actions menu (rewrite, summarize, continue writing), word count, and version history.
- An automation builder with a visual, vertical workflow editor (trigger/action/condition/output steps), execution history, and starter templates.
- Usage analytics with daily/weekly trend charts, model distribution, request categories, top prompts, and an exportable usage history table.
- Billing with plan comparison, plan switching, cancellation, invoice history, and payment method management.
- Team management with roles, invitations, member removal, and a shared activity timeline.
- An API keys interface with masked keys, permission levels, and a one-time key reveal on creation.
- Notifications with categories, unread state, and mark-as-read/mark-all-as-read.
- A help center with search, categories, and popular articles.
- Full settings: profile, workspace, security, and notification preferences, plus appearance, compact mode, and reduced-motion controls.
- Dark and light themes, respecting `prefers-reduced-motion` and offering a manual reduced-motion override.
- Complete documentation set covering installation, structure, customization, theming, mock data, state management, deployment, and troubleshooting.
