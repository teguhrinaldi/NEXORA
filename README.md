# NEXORA

Your intelligent workspace — a premium AI SaaS dashboard template built with Next.js 16, TypeScript, and Tailwind CSS.

NEXORA is a complete frontend starter kit: a marketing site, authentication and onboarding flows, five dashboard variations, an AI Studio, a chat workspace, a prompt library, a document workspace, an automation builder, usage analytics, billing, team management, and full settings — all working against local, typed mock data so you can explore the entire product immediately and wire up a real backend when you're ready.

## Quick start

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Documentation

Full documentation lives in [`docs/`](docs/README.md), including installation, project structure, customization, theming, mock data, state management, deployment, and troubleshooting guides.
